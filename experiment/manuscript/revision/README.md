# MM-Kla CSBJ revision

`manuscript.tex` is the revised research article. `figures_generated/` contains
data-derived vector figures and the table generated by
`../analysis/generate_results.py`. The architecture diagram in Figure 1 is
author-supplied and remains a marked placeholder.

The article uses the CSBJ Science Partner Journals two-column structure and
numeric citations. The local TeX installation lacks the journal template's
`biblatex`/`nejm` package, so this build uses `natbib` with `unsrtnat` while
retaining the template's main section order. The author team should check the
final project against the official CSBJ template before upload.

Build from this directory:

```bash
pdflatex manuscript.tex
bibtex manuscript
pdflatex manuscript.tex
pdflatex manuscript.tex
```

The source, figures, and bibliography compile without undefined references
or overfull boxes in the verified local build. Metrics are single-seed results
for the locked CLEAR-Lactyl internal test, not a separate-study external test.
